# Streetfighter Game Graphics

## Code

`mif_maker.py` is used to create mif files of a given image in the directory  
`mif_stitch_maker.py` is used to stitch multiple mif files together  
`strip_maker.py` creates vertical strips of each character frame for animation purposes
